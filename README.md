# Beyond The Noise (beyond-the-noise)

**A Minimalist, Professional Journalism & Research Publishing Platform**

> *"When information is abundant, the only scarce resource is the clarity required to separate reality from algorithmic momentum."*

---

## 🌟 Key Features

1. **Minimalist Editorial Aesthetics:** High-contrast, typography-focused editorial layout inspired by classic journals (*The Atlantic*, *The Verge*, *Aeon*), built with modern web variables and Google Fonts (`Newsreader` + `Inter` + `JetBrains Mono`).
2. **Video Essays & Documentaries:** Dedicated cinematic video player section with responsive 16:9 embeds, metadata badges, duration chips, and a one-click modal to embed custom YouTube/Vimeo or local MP4 files.
3. **Special Reports & Whitepapers:** Primary-source record section with interactive summary previews, file size indicators, and one-click download handlers.
4. **Interactive Dispatch Reader:** Full-screen modal reader for long-form investigations without leaving the homepage or causing page reloads.
5. **Dark / Light Theme Toggle:** Instant persistence using `localStorage`.
6. **Zero Dependencies / Framework Bloat:** 100% vanilla HTML5, CSS3, and ES6 JavaScript. Fast loading and ready to deploy on any static host (Vercel, Netlify, GitHub Pages).
